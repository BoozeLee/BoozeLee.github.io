# Security Policy

This repository is a static portfolio site. It has no server-side code, no
database, and no user accounts, so there is very little here to attack. The
most realistic issues are a broken link, an outdated or incorrect claim, or a
mistakenly published file.

## Reporting a problem

Please do not open a public issue. Email me instead:

- **Email:** bakerstreetbandit@zohomail.eu

Please include the file or URL, what you expected, and what you saw. For a
factual correction to the portfolio text, a one-line email is enough.

## What I will do

- Acknowledge within 72 hours.
- Fix a factual error or a dead link quickly.
- For anything that would need real work, say so plainly rather than let you
  wait.

## A note on the numbers

Every figure on the portfolio page comes with the command that reproduces it,
pinned to a specific commit. If you run one of those commands and get a
different number, that is a bug in the page, and I want to know — please email
it with the output you got.
