# Security Policy

## Reporting a Vulnerability

If you find a vulnerability, please do not open a public issue. Instead, report it privately:

- **Email:** security@boozelee.com (or via GitHub Private Vulnerability Reporting)
- **Response:** We strive to respond to all reports within 48 hours.

## Security Updates
All security-critical repositories are monitored for dependencies. Please keep all software updated to the latest release.
