# Kiliaan Vanvoorden Portfolio

This repository powers the GitHub Pages portfolio at
<https://boozelee.github.io>.

The site is intentionally simple: a static `index.html` served by GitHub Pages
with Jekyll support for supporting markdown pages. Its purpose is to present
selected working projects for software engineering, AI engineering, automation,
and internship applications.

## Local Validation

```bash
bundle exec jekyll build
```

## Content Policy

- Link only to public repositories that are working, documented, or useful as
  portfolio evidence.
- Keep claims specific and verifiable.
- Avoid publishing private contact details, unfinished experiments, or migrated
  placeholder repositories.
