Case studies

elohim — a gate for numerical claims

Problem: an AI system that publishes numbers nobody can re-derive is indistinguishable from one that makes them up. Every evaluation dashboard is one silent regression away from becoming a lie.

Approach: pin every published number to a checksum, re-derive each value independently, and refuse to pass anything it cannot classify. Six measurement instruments each catch a different class of false claim; the seventh, reproducibility, monitors the other six.

python3 tests/test_all.py # → ALL_SKILLS_PASS

Outcome: 81 facts classified, 107 checksum-pinned values, 0 unclassified. 6/6 seeded tampering attempts caught — each emits verdict FAIL + PIN DRIFT naming the altered file. 26 commits, 20,639 non-blank Python lines, measured at 114f660. MIT, CI + CodeQL green.

harness — the AI engineering pipeline, measured against the agent it replaces

Problem: coding agents report success whether or not they succeeded. A pipeline that passes every gate without evidence has passed nothing.

Approach: scan → task → verify → pr: a guard hook blocks protected-path writes and secret reads before the edit lands, every claim is bound to measured evidence, and a PR refuses to open unless the verdict is PASS — a skipped review counts as not passed.

pip install git+https://github.com/BoozeLee/harness.git
pytest # → 88 passed
harness scan --fail-under 70 # exits 1 below the readiness floor

Outcome: 11/13 graded PASS (raw vs harnessed evaluation against a hidden acceptance suite), 88 tests, 11 subcommands, 48 commits. Scope violations: raw 3, harnessed 4 — published because the harness cannot improve what it hides. Wheel + sdist build via uv build. AGPL-3.0.

terminal221b — a coding CLI bounded to a workspace

Problem: token budgets do not bound what an agent can read or write — they only limit what it can request. An agent that over-reads and over-writes is silently dangerous.

Approach: bound context by path, not by token budget. Redact credentials out of stored transcripts before they reach disk — with a test that fails if a secret survives. Ship a TypeScript CLI alongside a Rust ratatui TUI and an Expo mobile client.

npm ci && npm test # → 385 passed
cargo test # → 60 passed

Outcome: 445 tests total (385 TypeScript + 60 Rust). 55 commits, 16,210 non-blank lines. Test modules cover the containment properties (path-guard, boundary-drift, scope), not just the happy paths. AGPL-3.0.
